The problem

      
You paste production secrets into random websites.

      
Every developer does it: a JWT to see why login fails, a webhook body to check a signature, a customer's JSON to find the broken comma. Most online formatters are free because of what you paste into them.

      

        
!
Tokens carry real dataA JWT holds user IDs, emails and roles. Paste it into the wrong site and it's in someone else's logs.

        
!
Secret keys are worth stealingA Paystack or Stripe secret key pasted into an HMAC site lets that site move money as you.

        
!
"Client-side" is just a claimPlenty of sites say "we don't store anything" and still send your input to analytics.

      

    

    

      
How DevKit is different

      
DevKit ships with a strict Content-Security-Policy. The browser itself refuses any connection to another server, so even a bug or a bad dependency couldn't send your data out.


<meta http-equiv="Content-Security-Policy"
  content="default-src 'self';
           script-src 'self';
           connect-src 'self';
           form-action 'none'">

      

        
Check it yourself: DevTools → Network, then paste anything.

No requests. Your data stayed on your machine.

FAQ
Questions

    

      
Is it really private?
Yes. Every tool runs as JavaScript in your browser tab. The page's Content-Security-Policy (connect-src 'self') tells the browser to block requests to any other server, so even if we wanted to send your data somewhere, the browser wouldn't let us. The code is open on GitHub if you'd like to read it.

      
How can I check that nothing is sent?
Open DevTools (F12 or ⌥⌘I), go to the Network tab, then use any tool. You'll see no requests carrying your input. You can even turn off Wi-Fi: once DevKit has loaded, it keeps working.

      
Is it free?
Yes, all 23 tools, with no account and no limits. There are no ads and no trackers.

      
Does it remember what I paste?
Some tools keep your last input in your browser's local storage so it's there next time. It never leaves your device, and clearing your site data removes it.

      
Why is "Show real previews" in the Font picker allowed to load fonts?
That one button downloads font files from Google Fonts so you can see them. It only fetches fonts; nothing you type is part of the request, and nothing loads until you press it.

      
Can I suggest a tool?
Please do. Open an issue on GitHub with what you keep looking up.
